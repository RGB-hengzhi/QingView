# 轻看 0.1.1 滚轮缩放修复

验收日期：2026-10-10。本次修复针对鼠标滚轮缩放幅度过大。

原来滚轮与按钮共用 25% 的步长；默认关闭分数缩放时，任何非零小幅
滚动也会触发完整一步。现在滚轮独立使用默认 5% 的幅度，并按实际滚动量
连续计算。同样累计滚动量分成多个事件时结果一致，正反等量滚动可恢复
原尺寸。工具栏及键盘的默认 25% 步长保持原值。

「工具 → 设置 → 图像 → 滚轮缩放幅度」可设置 1%—50%。已有设置缺少
新选项时使用 5%，无需重置其他偏好。触控板只有像素增量时也可细调。
