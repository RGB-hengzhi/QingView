# 轻看 0.1.0 首版验收

验收日期：2026-10-10。上游为 qView 7.1，固定提交
`0ec246b78c310d5c842836a91566db24037c75c2`。

## 本机与交付

- Apple M6、16 GiB 内存；macOS 27.0.1（26A434）。
- Qt 6.8.3，release，单一 arm64 架构；最低部署目标 macOS 12。
- 中文名称「轻看」，独立的 `local.qingview.QingView` 标识与设置。
- 编译排除更新器，移除远程图片下载实现与 QtNetwork 依赖；粘贴、拖入仅接收本地文件。
- 本地 ad-hoc 签名，复制至外置盘后执行深度、严格签名校验。
- 安装位置：`/Applications/轻看.app`，已实际启动。
- 在 Finder 的「打开方式 → 轻看」打开 HEIC 后，已安装进程显示该图片。
- 压缩包 11,440,338 字节；解压后的应用再次通过深度、严格签名校验。

交付程序 SHA-256：
`a04fa6be208f2557043c24931d84a9ba928886dcbc76c7720236c4f475561a12`。

首版保留 qView 的成熟解码、排序与浏览逻辑，增加中文空窗口、原创图标、
自动隐藏的九按钮工具栏。旋转只改变显示方向。窗口最低 340 × 240，
工具栏不改变图片视口的布局尺寸。

## 功能验收

`tests/results/integration.txt` 与 XML 报告：**24 passed，0 failed，0 skipped**。
运行于真实 Cocoa 窗口，以应用源码、事件循环和实际图片解码器完成检查。
设置使用临时目录，避免污染用户设置。

覆盖 JPEG、PNG、WebP、HEIC、EXIF 方向、透明图片、中文路径和 6000 × 4000
大图；`1、2、10` 自然排序和键盘翻图；缩放、适应窗口、100% 和滚轮；
旋转后的实际像素；原生全屏与 Esc；损坏文件后的恢复；GIF 可见帧变化、
暂停和逐帧；Finder 文件打开事件；九按钮、文件名/序号/比例、自动隐藏、
鼠标唤起及悬停保持。

追加验证远程 URL、HTTP 剪贴板和拖放不会替换本地图，本地 URL 仍可打开；
SVG 保留比例与象限像素；六个窗口的解码、预加载和打开方式任务排队后，
先销毁窗口，再释放工作线程，后续正常图片仍可打开。

为此修复上游异步任务的窗口生命周期风险：后台解码仅接受路径、颜色空间和
屏幕尺寸的值快照，SVG 在后台渲染到 QImage；打开方式查询捕获路径值；
缓存 watcher 随图片对象释放。

## 最终包独立性

`formats/packaged-format-check-result.json`：**13 项格式检查全部通过**。
诊断程序只搜索应用内图片插件，实际加载的 Qt 库均来自应用包。

`formats/packaged-dependency-check-result.json` 记录最终二进制的 SHA-256、
架构和每条依赖。所有非系统依赖均可解析到包内文件，未使用开发 SDK 的
绝对依赖或外部 RPATH。开发 SDK 不需要随用户日常运行保留。
最终共 20 个 Mach-O、275 条有效依赖；包中不再含 QtNetwork 或其网络插件。

## 内存采样

对独立打包版本做一次实际运行采样，非同条件的跨应用性能比较。

| 状态 | macOS physical footprint | RSS |
| --- | ---: | ---: |
| 启动后的空窗口 | 35.3 MiB | 约 120 MiB |
| 通过原生打开对话框载入 2400 万像素 JPEG | 232.3 MiB | 约 329 MiB |

RSS 包含驻留的共享库；physical footprint 为系统计入该进程的物理内存。
大图样本所在文件夹同时有其他测试图片，默认邻图预加载开启，打开对话框也
参与本次使用过程，因此这些数值不是仅解码一张图的最小内存。两个采样时刻
`ps` 显示 CPU 0.0%。没有测量冷启动、连续翻图速度或所有场景的峰值。
原始证据在 `tests/results/empty-*`、`large-*`。
